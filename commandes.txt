=== RÉSUMÉ DES RELATIONS DU MCD ===

1. ADRESSE (1,N) LIVRER_A → COMMANDE (0,N)
2. CLIENT (1,N) PASSER → COMMANDE (0,N)
3. COMMANDE (0,N) COMPOSER → PRODUIT (0,N) [via table Composer]
4. PRODUIT (1,N) ETRE_STOCKE → STOCK (0,N)
5. RAYON (1,1) POSSEDER → STOCK (1,N)


=== TABLES CRÉÉES DANS LA BASE DE DONNÉES ===

1. adresse
   - id (PK, AUTO_INCREMENT)
   - rue (VARCHAR 255)
   - code_postal (VARCHAR 10)
   - ville (VARCHAR 100)
   - pays (VARCHAR 100)
   - complement (VARCHAR 255, NULL)

2. client
   - id (PK, AUTO_INCREMENT)
   - adresse_id (FK → adresse.id)
   - role (VARCHAR 50)
   - nom (VARCHAR 100)
   - prenom (VARCHAR 100)
   - email (VARCHAR 255, UNIQUE)
   - mot_de_passe (VARCHAR 255)
   - telephone (VARCHAR 20, NULL)
   - date_inscription (DATETIME)

3. commande
   - id (PK, AUTO_INCREMENT)
   - client_id (FK → client.id)
   - adresse_id (FK → adresse.id)
   - numero_commande (VARCHAR 50, UNIQUE)
   - statut (VARCHAR 50)
   - mode_livraison (VARCHAR 100)
   - date_commande (DATETIME)

4. produit
   - id (PK, AUTO_INCREMENT)
   - nom_produit (VARCHAR 255)
   - description (TEXT, NULL)
   - prix_vente (DECIMAL 10,2)
   - image_url (VARCHAR 255, NULL)

5. rayon
   - id (PK, AUTO_INCREMENT)
   - nom_rayon (VARCHAR 100)
   - description (TEXT, NULL)

6. stock
   - id (PK, AUTO_INCREMENT)
   - rayon_id (FK → rayon.id)
   - produit_id (FK → produit.id)
   - lieu_stockage (VARCHAR 100)
   - quantite_disponible (INT)

7. composer
   - id (PK, AUTO_INCREMENT)
   - commande_id (FK → commande.id)
   - produit_id (FK → produit.id)
   - quantite (INT)
   - prix_unitaire (DECIMAL 10,2)
   - sous_total (DECIMAL 10,2)

  GET  /panier/confirmation/{id}  → app_panier_confirmation (confirmation commande, ROLE_USER requis)

Note : La validation du panier crée une vraie entité Commande + entités Composer en base de données.
